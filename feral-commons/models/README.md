# Feral Commons model library

Drop .glb files here (Add file → Upload files on GitHub). Every headset that opens
Feral Commons sees them in the World tab, and the **My models** / **Both** field uses them.

- Put the height in the file name: `tower_10m.glb`, `blob_3.5m.glb`. No number means 4 m.
- Texture colours or vertex colours are baked in automatically.
- .gltf (single file), .fbx, .obj and .ply work too. Keep each file under 25 MB.
