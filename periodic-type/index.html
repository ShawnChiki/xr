The table

One frame for every character. Tap one to sculpt it. Sculpted ones show what they flatten into.

Beat rush

A game: each letter gets a few beats. Either it jumps to the next one on the beat, or it waits for you to press Space (or the Ready button) so you start each letter when you're set. Space also ends a letter early.

Look

How the 3D sculpture gets flattened into a black-and-white letter. Changes apply to every letter.

Type

Write anything to see it set in your letters. Missing letters show as dashed boxes.

Font

Download an .otf font. On Windows: double-click the file, then press Install. It then shows up in Word, Illustrator, Photoshop and the rest.
