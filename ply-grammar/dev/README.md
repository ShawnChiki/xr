# Ply Grammar: source parts and tests

`../index.html` is the built app. It is assembled from these parts:

- `head.html`: markup, styles, the settings diagrams (generated by `diag.py`)
- `pre.js`: default settings
- `geom.js`: geometry helpers (planes, polygons, Clipper)
- `post.js`: everything else (panelizing, ribs, screws, nesting, build order, tests, headset)

## Build

    python3 regen.py     # head.html + pre.js + geom.js + post.js -> one page (edit the output path at the bottom of regen.py)
    python3 mkgh.py <built page> ../index.html   # wraps it as a full document with the password gate on

## Tests (Node, need `npm i three@0.160.0 clipper-lib@6.4.2` beside them)

    python3 mkh.py fz.js && node h.mjs 400     # torture test: 400 random obstacles through panelizing, overlap, build-order and fit checks
    python3 mkh.py test9.js && node h.mjs      # the original boxes
    python3 mkh.py cv.js && node h.mjs         # cut-outs: step, tunnel, sloped corner, 110" box
    python3 mkh.py dn.js && node h.mjs         # holes through the middle

Run the torture test before every push. On 13 Nov 2026 it stood at: plain boxes 100% clean, boxes with cuts 100%, boxes with cut-outs 97%.
`node h.mjs 1 1 <seed>` prints one failing shape so it can be looked at.
