# Dwindle Doodle saves

Dwindle Doodle (`../dwindle-doodle/`) writes here when GitHub is connected in the app:

- `worlds/` — one file per world (the full stroke log). Open the app on any device to keep sculpting.
- `exports/` — `.glb` files sent from the headset. Download one and use File › Import › glTF 2.0 in Blender.
- `index.json` — the list of worlds the app shows on its start screen.
